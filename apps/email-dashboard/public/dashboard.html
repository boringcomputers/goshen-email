    API keys

    An account key works across your inboxes through the REST API, CLI, and MCP server. It reaches only the scopes you pick, until it expires or you revoke it.

    Scopes are fixed when a key is created. To limit an agent to one inbox, create a mailbox key from that inbox instead.

    Integrations

    One account key works everywhere. Keep it in GOSHENEMAIL_API_KEY and point your client at the URLs below.
