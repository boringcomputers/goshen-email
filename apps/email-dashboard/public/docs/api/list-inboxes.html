API reference / Inboxes

List inboxes

List a page of account inboxes, optionally filtered by group. Pass nextPageToken as pageToken. Mailbox keys list only their assigned inbox and cannot filter groups or use page tokens.

GET/v1/inboxes

Requires an API key with the inboxes:read scope. MCP tool: list_inboxes. CLI: goshenemail inboxes list.

Request

Query parameters

NameTypeRequiredNotes
limitinteger1–100, default 50
pageTokenstring1–1024 characters
groupstring1–64 characters

Response

FieldTypeNotes
inboxesobject[]
inboxIdstring
addressstring
displayNamestring
createdAtstring
groupstring | null
deliveryStatus"pending" | "ready"
setupAvailableboolean
nextPageTokenstring

Errors return { "error": { "code", "message", "transient" } } with a 4xx or 5xx status. See Errors.

Examples

curl

curl "https://api.goshenemail.com/v1/inboxes" \
  -H "Authorization: Bearer $GOSHENEMAIL_API_KEY"

CLI

goshenemail inboxes list
